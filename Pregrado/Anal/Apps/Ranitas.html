Conquistar BFS encuentra una solución con el mínimo número de movimientos.
1. Las ranas verdes → solo avanzan hacia la derecha.
2. Las ranas azules ← solo avanzan hacia la izquierda.
3. Una rana puede avanzar una casilla si está vacía.
4. También puede saltar sobre exactamente una rana y caer en la casilla vacía.
5. Ninguna rana puede retroceder.
rana → rana ← movimiento legal

Con n ranas por lado, la solución óptima tiene n² + 2n movimientos.

Se muestra el árbol BFS explorado hasta hallar la meta. El camino solución se resalta con trazos más gruesos. 
BFS(inicio, meta)
cola ← [inicio]
visitados ← {inicio}
padre[inicio] ← ∅

mientras cola no esté vacía:
    actual ← sacar_primero(cola)

    si actual = meta:
        reconstruir_camino()
        terminar

    para vecino en movimientos_legales(actual):
        si vecino no está visitado:
            visitados.agregar(vecino)
            padre[vecino] ← actual
            cola.agregar(vecino)

BFS funciona aquí porque cada movimiento tiene el mismo costo: una jugada. Por eso, la primera vez que BFS alcanza el objetivo, el camino encontrado es mínimo.
