Cómo interpretar la evaluación

La estandarización se ajusta solo con redes de entrenamiento. Comparar muchos modelos sobre la misma prueba puede sesgar la elección; estos resultados son una demostración didáctica, no una validación externa.

Una fila por grafo

¿Qué es graph prediction?

La unidad de predicción es la red completa. La clasificación entrega una categoría; la regresión, un número. Cada grafo tiene su propio conjunto de nodos y enlaces.

En este laboratorio usamos aprendizaje clásico con atributos globales: grafo → vector de características → modelo → respuesta. No es una GNN.

Recorrido para clase

1. Explora varias redes sin revelar las respuestas.
2. Observa cómo se resume cada una en una fila.
3. Usa solo grado medio y compara.
4. Añade clustering y variación de grados.
5. Cambia de modelo con la misma partición.
6. Prueba la regresión y el control aleatorio.

Clasificación

Las categorías describen el generador de la red. Las redes aleatorias y las alternativas tienen densidades esperadas similares; no siempre basta con contar enlaces para distinguirlas. El control aleatorio asigna las etiquetas independientemente de la estructura.

Regresión: resistencia estructural

El valor real se obtiene retirando simultáneamente el 15 % de nodos de mayor grado inicial (redondeado hacia arriba, desempate por identificador). La respuesta es la fracción de nodos restantes que queda en la componente más grande.

Los atributos de entrada se calculan antes de retirar nodos. El valor objetivo se calcula después y no se incluye como atributo. El modelo aproxima ese experimento para otras redes sintéticas.

Atributos invariantes

Cambiar el layout o arrastrar nodos no cambia la predicción. El modelo usa la topología, no las coordenadas del dibujo.

Límites

Datos sintéticos y una sola partición. Las probabilidades no están calibradas externamente. La opción de reservar una red permite practicar una separación manual; elegirla tras mirar resultados puede sesgar la evaluación.
