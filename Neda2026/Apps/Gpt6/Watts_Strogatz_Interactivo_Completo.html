Un solo grafo, una curva en construcción

Pulsa Animar para introducir reconexiones. La curva empieza con el estado regular y agrega únicamente medidas de los estados que se van mostrando. «Un paso» reconecta un enlace. El deslizador de progreso puede reconstruir la trayectoria hasta un número elegido de reconexiones.

Partimos de un anillo con N nodos y k/2 vecinos a cada lado. Recorremos los enlaces por distancia horaria d = 1,…,k/2 y nodo origen. Para p objetivo fijo, cada enlace se selecciona con probabilidad p. El nuevo destino se elige al azar excluyendo el propio nodo y los vecinos ya conectados: no hay bucles ni duplicados. M = Nk/2 permanece constante; los grados individuales pueden variar.

Cᵢ = 2tᵢ / [kᵢ(kᵢ − 1)]
C = (1/N) Σ Cᵢ
L = [2 / N(N − 1)] Σᵢ<ⱼ d(i,j)

C es el promedio del clustering local (Cᵢ = 0 si kᵢ < 2). L es el promedio exacto de todos los caminos mínimos calculados con BFS. Una red desconectada tiene L = ∞; se marca en la gráfica y no se une como un valor finito.

El eje horizontal es r = reconexiones realizadas / M, no una nueva probabilidad p en cada paso. Los estados intermedios de una ejecución ordenada no son muestras independientes del modelo WS para p = r. Para comparar las medidas se normalizan respecto a C₀ y L₀. El eje logarítmico destaca los primeros atajos; r = 0 aparece separado. Puedes cambiar a escala lineal.

La zona verde indica C/C₀ ≥ 0,8 y L/L₀ ≤ 0,5: un umbral didáctico, no una definición universal. Al aleatorizar más, el clustering también cae. Las medidas pueden fluctuar; no se fuerza una disminución monótona.

A velocidad alta se reconectan varios enlaces entre medidas y se dibuja un punto por lote. El cálculo sigue siendo exacto para cada estado mostrado; los estados intermedios dentro de un lote no se representan.

El layout Fruchterman–Reingold se calcula en un trabajador separado para mantener la interfaz fluida: repulsión k²/d, atracción d²/k y enfriamiento. Para más de 250 nodos se aproxima la repulsión con Barnes–Hut. Los nuevos enlaces actualizan el layout sin reiniciarlo en cada rewire. «Detener layout» fija las posiciones; arrastrar un nodo también detiene el cálculo. La vista circular de una red regular puede parecer un anillo incluso cuando un algoritmo de fuerzas alcanza un equilibrio.

Referencia del layout: Fruchterman y Reingold (1991), Graph drawing by force-directed placement.

Watts, D. J. y Strogatz, S. H. (1998). Collective dynamics of ‘small-world’ networks. Nature 393, 440–442. doi:10.1038/30918. El laboratorio funciona sin conexión.
