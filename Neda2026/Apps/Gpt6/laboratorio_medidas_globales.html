Retos para clase
  1. Compara estrella y anillo con el mismo n: ¿cuál tiene menor distancia media?
  2. Elimina el puente entre dos grupos. ¿Qué ocurre con eficiencia y componentes?
  3. En mundo pequeño aumenta β: ¿baja primero la distancia o el clustering?
  4. Compara clustering medio y transitividad en una red con hubs.
  5. ¿Puede cambiar una medida al cambiar solo el layout?

La estrella acorta caminos, pero depende del centro. Cortar un puente separa componentes y reduce eficiencia. Los atajos pueden reducir mucho las distancias conservando triángulos. El clustering medio pondera nodos; la transitividad pondera tripletas. Ningún layout modifica la topología ni sus medidas.

Explora la estructura, no solo el dibujo

1. Elige una red y ajusta su tamaño. 2. Selecciona una medida. 3. Pulsa Animar explicación para verla sobre la red.

Selecciona dos nodos sucesivamente para destacar un camino mínimo. Usa la acción de edición para crear o quitar enlaces entre dos nodos. Puedes arrastrar nodos, cambiar el layout y guardar una referencia para comparar antes y después.

Convenciones: las distancias medias se calculan entre pares alcanzables; el diámetro y radio de la red completa son infinitos si está desconectada. La eficiencia asigna cero a 1/∞. El clustering local vale cero para grado menor que dos. La asortatividad es Pearson entre grados en extremos de aristas; no se define si su varianza es cero.
